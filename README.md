# Gyan Inter College, Sikandra, Agra - Official Website

A multi-page website for **Gyan Inter College, Sikandra, Agra**, designed using the Google Stitch aesthetic with an academic **Red & White** theme.

## 🎓 About the College
- **Institution**: Gyan Inter College
- **Location**: Sikandra, Agra, Uttar Pradesh, India
- **Affiliation**: Approved & Affiliated to State University
- **Contact Helpline**: +91 6543223443
- **Official Email**: gyanintercollage@gmail.com

---

## 🏛️ Degree Programs Offered
- **B.A. (Bachelor of Arts)**: 3-Year Undergraduate Program (NEP 2020) in Humanities & Social Sciences.
- **B.Sc. (Bachelor of Science)**: 3-Year Undergraduate Program in PCM (Physics, Chemistry, Maths) and ZBC (Zoology, Botany, Chemistry).
- **M.A. (Master of Arts)**: 2-Year Postgraduate Program in Hindi, English, History, and Political Science.
- **M.Sc. (Master of Science)**: 2-Year Postgraduate Program in Mathematics, Chemistry, and Physics.

---

## 💻 Tech Stack & Design Features
- **Semantic HTML5** & **Tailwind CSS** (configured with the custom collegiate Red & White theme)
- **Typography**: Playfair Display (Serif headings) + Plus Jakarta Sans (Clean body & UI labels)
- **Icons**: Google Material Symbols Outlined
- **Interactive Features**:
  - Live Admissions Notice Ticker
  - 3-Slide Hero Carousel with manual and automated slide controls
  - Interactive Tab Switcher for College Vision & Mission
  - Interactive Course Syllabus & Curriculum Details Modal
  - Fast-Track Admission Enquiry Form with instant submission feedback
  - Responsive Mobile Navigation Drawer

## 🚀 How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/kanishka290107/college-website-2.git
   ```
2. Open the directory:
   ```bash
   cd college-website-2
   ```
3. Start a local server:
   ```bash
   python -m http.server 8080
   ```
4. Open your browser and navigate to `http://localhost:8080`.
